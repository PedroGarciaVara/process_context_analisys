# Engram Convention

Topic key format for engram mode:

- sdd-init/{project}: Project context
- sdd/{change-name}/explore: Exploration artifact
- sdd/{change-name}/proposal: Proposal artifact
- sdd/{change-name}/spec: Spec artifact
- sdd/{change-name}/design: Design artifact
- sdd/{change-name}/tasks: Tasks artifact
- sdd/{change-name}/apply-progress: Apply progress
- sdd/{change-name}/verify-report: Verify report
- sdd/{change-name}/archive-report: Archive report
- sdd/{change-name}/state: DAG state
